# Reyan Collections v1: Plan Roadmap

Spec: `docs/superpowers/specs/2026-10-26-reyan-collection-design.md` (approved 2026-10-26)

v1 is built in five plans, one per milestone. Each plan is written **after the previous one lands**, so it can use the real generated types and file layout instead of guesses. Each plan ends with working, tested software.

| # | Plan | Spec milestones | Delivers | Status |
|---|---|---|---|---|
| 1 | `2026-10-26-01-foundation-and-content-model.md` | M1 + M2 | Scaffolded app on local Postgres. The full content model (media, users, categories, curated collections, pages, products with variants, homepage/navigation/links/settings globals). Seed data. Branded admin. Admin E2E. | **Written** |
| 2 | `…-02-storefront.md` | M3 | Tokens/fonts and the Playful Pop components. Home, `/links`, shop/category/collection, product (variant picker, live stock, delivery check UI on a stub), CMS pages, SEO, on-demand revalidation. | After plan 1 |
| 3 | `…-03-checkout-and-orders.md` | M4 | Orders, discountCodes, codBlocklist, rateLimits, invoiceCounters schema. Pricing/eligibility/state machine (unit-tested). Quote and checkout endpoints, stock reservation, Turnstile, mock Razorpay, the order page and `/track`. | After plan 2 |
| 4 | `…-04-admin-operations.md` | M5 | Today view, order actions panel, WhatsApp confirmation, mock Shiprocket and webhooks, GST invoice PDF, packing slips, jobs (expiry, polling), emails (mock). | After plan 3 |
| 5 | `…-05-go-live.md` | M6 | Live adapters verified with test keys, R2, Railway, Cloudflare, Resend domain, migrations, backups, uptime, Lighthouse pass, logo vectorised. | After plan 4, when accounts exist |

E2E journeys from spec §16: journey 3 (admin content) starts in plan 1 (admin half) and is completed in plan 2 (storefront half). Journeys 1, 2 and 4 land in plans 3–4.
