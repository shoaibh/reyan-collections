# Plan 2: Storefront, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The public Playful Pop storefront, mobile-first, reading published content from Payload: the home page, `/links`, shop/category/collection listings, the product page (colour variants, live stock, delivery check), a cart drawer, CMS pages and SEO. Pages refresh when Shoaib publishes in the admin.

**Architecture:**
- Server components read Payload through **one data layer** (`src/lib/data/*`). It always queries with `overrideAccess: false`, so only published content is visible, and it caches with tags. Payload `afterChange`/`afterDelete` hooks invalidate those tags.
- Interactive pieces are small client islands: the variant picker, stock, the delivery check, and the cart (localStorage).
- `/links` uses a bare layout. Every other page uses the site layout (announcement, header, footer, WhatsApp button).

**Tech Stack:** Next.js 16.3 (App Router), Payload 3.92 local API, Tailwind CSS 4.3 (`@tailwindcss/postcss`), `next/font` (Bricolage Grotesque), `@payloadcms/richtext-lexical/react`, Playwright (+ `@axe-core/playwright` 4.14), Vitest.

**Spec:** `docs/superpowers/specs/2026-10-26-reyan-collection-design.md`. Read §4–§6, §7, §13 and §14. Visual references, which **must be matched closely**:
- `docs/design/mockups/home-logo.html`: header lockup with the house mark, footer with the circle logo, links page
- `docs/design/mockups/home-playful.html`: all home sections, product cards, the "why direct" band, the mobile layout

Roadmap: `docs/superpowers/plans/2026-10-26-00-roadmap.md`.

## Review Focus

1. **Drafts leaking:** a product that has never been published, or whose latest version is a draft with a new title, must show its *published* data or 404, never draft text. Tested in Task 1.
2. **Fully out-of-stock product** (all variants 0):
   - The card shows "Out of stock".
   - The product page disables Add to cart and shows "Ask on WhatsApp".
   - Tested in Task 5.
3. **Sparse content renders cleanly:**
   - No compareAt, no boxImage, no description, no highlights.
   - Homepage `productA` unset, or set to an unpublished product (the hero falls back to an imageless layout, with no tag).
   - No ratings, no marketplace URLs.
   - Tested in Tasks 3 and 5.
4. **Horizontal overflow at 390px** on home, a listing, a product page and `/links`: `document.documentElement.scrollWidth <= 390`. Tested in Tasks 3–5.
5. **A stale cart:** a cart line whose product was unpublished, or whose variant stock dropped below the cart qty, shows "No longer available" (and can be removed) or clamps the qty with a notice. Tested in Task 6.
